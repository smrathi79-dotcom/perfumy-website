# 🌸 Perfumy - Perfume Website

## 📌 About the Project
Perfumy is a simple and elegant perfume website developed using HTML and CSS. It showcases different perfume products with attractive images and descriptions.

## ✨ Features
- Responsive navigation bar
- Search bar UI
- Perfume product cards
- Product images and descriptions
- About Us section
- Simple and clean user interface

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📸 Project Overview
The website displays perfume collections in a card layout with product images and descriptions. It also includes a navigation menu, search bar, and About Us section.

## 🎯 Objective
The main objective of this project is to practice HTML and CSS concepts and develop a simple, visually appealing product website.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
